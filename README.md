# TradeTrack
TradeTrack is an open‑source trading journal designed to help traders record, explore, and revisit their trades with ease. It provides a structured foundation for trade analysis and quantitative algorithm testing.

## Repository layout

- **`trade-track-frontend`** — [Vue 3 + Vite](trade-track-frontend/README.md) UI
- **`trade-track-backend`** — Python [FastAPI](trade-track-backend/README.md) API (quant, scraping, models)

Run the backend from `trade-track-backend` (see its README); default port is **5205**.
